# נדל״ן AI — מהדורת הנדל״ן (לוי)

מהדורת נדל״ן של מנוע הצ'אט (מבוסס Wisply של Goldstein Studio), לגיא ודורון לוי.
כמו Be.live: אותו מנוע חכם ובדוק, עם שכבת פרופיל אחת שזורעת את ההגדרות, ובנוסף
שלושה פיצ'רים ייעודיים לנדל״ן שנבנו במהדורה הזו בלבד (לא במנוע הכללי).

## מה היא עושה

- **סוכן/ת וירטואלי/ת בסגנון וואטסאפ** — אווטאר + שם + "מחובר/ת עכשיו", בועות
  בסגנון וואטסאפ, ו**וי כחול (נקרא)** שמתמלא כשהבוט עונה. נשלט דרך `chat_skin=whatsapp`.
- **גלריית פרויקטים** — הבוט מציג קרוסלת תמונות של פרויקטים (תמונה, שם, מיקום,
  טווח מחירים, קישור). מנוהלת ידנית במסך "פרויקטים", ו/או נזרעת אוטומטית מהאתר
  (כל עמוד/פוסט עם תמונה ראשית). הבוט פולט `[PROJECTS]` כדי להציג אותה.
- **קביעת פגישה** — כפתור שפותח בורר מועדים אוטומטי. המועדים נגזרים מחלונות
  הזמינות השבועיים של היועץ, פחות מה שכבר תפוס, פחות אירועים ביומן Google המחובר
  (free/busy). קביעה יוצרת אירוע ביומן Google ושולחת מייל התראה ליועץ. הבוט פולט `[BOOK]`.

## התקנה

1. דחסו את התיקייה `realestate-chatbot` ל-zip, העלו והפעילו בוורדפרס של הלקוח.
2. בתפריט הצד יופיע "נדל״ן AI". הפרסונה, מראה הוואטסאפ וזמינות ברירת מחדל (א׳–ה׳
   09:00–18:00) כבר מוגדרים.
3. הזינו מפתח API (OpenAI או Claude) בלשונית ה-AI.
4. במסך **פגישות**: חברו יומן Google (ראו למטה) והתאימו חלונות זמינות.
5. במסך **פרויקטים**: לחצו "משיכה אוטומטית מהאתר" ו/או הוסיפו פרויקטים ידנית.

## חיבור יומן Google (פעם אחת)

1. ב-Google Cloud Console צרו OAuth client מסוג **Web application**.
2. תחת *Authorized redirect URIs* הדביקו את הכתובת שמוצגת במסך "פגישות"
   (`<האתר>/wp-json/wisply/v1/gcal/callback`).
3. העתיקו את ה-Client ID וה-Client Secret למסך "פגישות", שמרו, ואז לחצו
   "חיבור יומן Google" ואשרו בחשבון הגוגל של היועץ.
4. הטוקן נשמר מוצפן (AES-256-GCM, אותה שכבה כמו מפתחות ה-API). ניתוק בלחיצה.

אם היומן לא מחובר: הפגישות עדיין נקבעות ונשמרות (והיועץ מקבל מייל), פשוט בלי
בדיקת התנגשות מול היומן וללא יצירת אירוע.

## הגדרות שנשלטות מהניהול

- מראה: `chat_skin`, צבעים, אווטאר, שם הסוכן, תפקיד (`agent_role_he`), נוכחות (`agent_status_he`).
- פגישות: זמינות שבועית, משך, מרווח, כמה ימים קדימה, אימייל להתראות, פרטי יומן Google.
- פרויקטים: רשימת הפרויקטים (JSON) + דגל משיכה אוטומטית.

## הערה ארכיטקטונית

שלושת הפיצ'רים (וואטסאפ-סקין, גלריה, מתזמן+יומן) הם **ייעודיים למהדורת הנדל״ן**,
בדיוק כמו ש-Logicare הוא Medical360-only. הם לא הועברו למנוע Wisply הכללי ולא
ל-Medical360. אם נרצה להפוך אותם למוצר אנכי חוזר, יש להעביר אותם ל-core בעתיד.
